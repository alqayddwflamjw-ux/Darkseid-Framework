# Darkseid-Framework (V2.0)
An automated hacking and stress-testing framework for Termux.

## Features
- **Auto-Stealth:** Automatically starts Tor and routes all traffic through Proxychains.
- **Deep Recon:** Integrated Nmap vulnerability scanning.
- **Power DoS:** Uses Impulse methods to test server stability.
- **Metasploit Integration:** Quick access to MSF with stealth.
